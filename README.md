# deal-o-mat

Assistent fürs Verkaufen gebrauchter Sachen: Artikel fotografieren, kurz beschreiben, und deal-o-mat recherchiert den Wert mit Quellen, schreibt den Anzeigentext, bereitet die Fotos auf und legt alles so bereit, dass es schnell in einer Anzeige auf Kleinanzeigen landet.

Was er können soll, steht in [docs/SPEC.md](docs/SPEC.md). Noch gibt es keinen Code.
